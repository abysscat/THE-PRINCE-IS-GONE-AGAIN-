王子又不見了！— 持續開發版

啟動方式：
1. 解壓縮整個資料夾。
2. 優先用 index.html 開啟遊戲；若瀏覽器限制音訊或本機檔案，請用本機 HTTP 伺服器開啟。

本版以使用者提供的「UI按鈕整合版」為基礎，保留原有畫面、角色、敵人、按鈕和音效。
本次調整：
- 開始／重新開始時重置角色狀態、攻擊冷卻、跳躍、敵人、血量與能量。
- 暫停時清除方向輸入，避免角色持續移動；繼續時也清除殘留按鍵。
- 返回標題時清理戰鬥狀態、恢復角色待機畫面、停止戰鬥音樂並切回標題音樂。
- 標題畫面隱藏戰鬥音樂按鈕，進入戰鬥才顯示。

注意：已做程式碼／檔案路徑檢查，尚未在你的電腦與實際瀏覽器中完成遊玩驗收。
