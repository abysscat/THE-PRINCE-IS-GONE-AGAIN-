王子又不見了！— JavaScript 新手閱讀指南（第四階段）
=====================================================

先記住：每個 .js 檔案是一個不同工作的抽屜。想修改某項功能，先找對抽屜。

一、檔案各自負責甚麼
--------------------
js/game-settings.js
  放「設定資料」：關卡目標數字、背景圖路徑、角色圖片路徑、大絕影格設定。
  想改圖片檔名或某些固定設定，先看這裡。

js/player.js
  放「角色畫面工具」：切換角色顯示圖片，以及設定大絕影格的大小和位置。
  目前還沒有把角色移動、跳躍、攻擊全部搬過來。

js/enemies.js
  放「敵人圖片路徑規則」：根據敵人種類和動作，決定使用哪張圖片。
  例如骷髏兵待機、皇家旗手、頭目等。
  目前還沒有把敵人生成、移動、攻擊或血量搬過來。

js/game.js
  是「遊戲流程總管」：開始遊戲、重開、暫停、關卡切換、角色操作、敵人生成、
  戰鬥判定、Q 大絕執行和遊戲主迴圈仍在這裡。
  之後會繼續逐小部分搬出，避免一次改太多導致遊戲無法開始。

二、網頁載入次序
----------------
index.html 依次載入：
  1. game-settings.js
  2. player.js
  3. enemies.js
  4. game.js

原因：game.js 會使用前面檔案提供的工具，所以工具必須先載入。

三、這次新增的 enemies.js 怎樣工作？
------------------------------------
enemySpritePath(type, state)
  type = 敵人種類，例如 "skeleton"（骷髏兵）或 "boss"（頭目）。
  state = 動作，例如 "idle"（待機）或其他動作名稱。
  回傳值是一個圖片路徑字串，例如 images/enemies/custom/5/enemy_nornal.png。

這個函式只負責「找圖片路徑」，不會建立敵人，也不會令敵人攻擊。
建立敵人和戰鬥仍由 game.js 處理。

四、常見英文詞
--------------
function：函式，可以理解為一項可重複使用的小工作。
const：建立一個不打算重新指向其他值的變數。
return：把結果交回呼叫它的程式。
type：種類。
state：狀態／動作。
src：圖片或媒體的來源路徑。
HUD：遊戲畫面上的血量、能量、關卡等資訊。

五、這次改動範圍
----------------
只把敵人圖片路徑判斷移到 enemies.js，並讓 game.js 呼叫它。
沒有刻意更改敵人生成、敵人數值、傷害、關卡、按鍵或遊戲迴圈。
請實際開啟遊戲測試後，再進行下一次分拆。
