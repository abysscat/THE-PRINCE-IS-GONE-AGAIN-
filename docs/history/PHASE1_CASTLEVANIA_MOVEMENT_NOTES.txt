《王子又不見了！》Phase 1 — 惡魔城式移動系統

本版本以最新上傳 ZIP 為基礎，保留原有：
- 4 關流程與背景
- 原有敵人、Boss、HP / MP
- 槍刺、盾擊、Q 大絕
- 王子線索、開始／暫停／標題畫面
- 鍵盤與觸控按鈕
- 原有音樂及音效

Phase 1 新增／重做：
1. 水平移動由瞬間定速改成加速與減速（較有 2D Action Platformer 重量感）
2. 空中控制獨立於地面加速度，避免空中轉向過度靈敏
3. 跳躍改成真正速度 + 重力，不再只靠 CSS 計時動畫
4. 加入最大下降速度，令落地節奏穩定
5. 加入 Coyote Time（土狼時間，約 105ms）
6. 加入 Jump Buffer（跳躍預輸入，約 120ms）
7. 保留原有跳躍圖片及戰鬥判定對 jumpT 的相容性
8. 每關切換／重開／返回標題時會重置移動物理狀態

操作：
← / →：移動
↑：跳躍
Z：槍刺
X：盾擊
Q：大絕
畫面按鈕亦保留。

下一階段建議：平台碰撞、上下層地形、Drop-through platform、Dash / Backstep。
