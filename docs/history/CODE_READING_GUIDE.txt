《王子又不見了！》程式閱讀指南（第三階段易讀版）

這個版本的重點
- 只整理 js/game.js 的排版，加入章節解說；不刻意更改遊戲規則或數值。
- js/game-settings.js：集中放關卡目標、圖片路徑、大絕影格比例等設定。
- js/player.js：處理角色圖片切換與大絕影格顯示的兩個小工具。
- js/game.js：負責把所有部分串起來，控制遊戲實際運作。

如何閱讀 game.js
建議由上至下，每次只看一個區域：
1. 開頭的變數區：保存目前關卡、角色位置、血量、能量、按鍵狀態等遊戲資料。
2. 圖片與角色顯示：預載角色圖片，並呼叫 player.js 的顯示工具。
3. 音樂與音效：開始／停止背景音樂，以及播放槍刺和盾擊音效。
4. 畫面與關卡：調整世界大小、鏡頭位置、HUD 數值、敵人生成與清除。
5. 遊戲初始化 setup()：玩家按開始或重新開始時，重設角色、敵人、血量、能量和關卡。
6. 戰鬥 attack()：處理普通攻擊、盾擊和特殊技能的命中、傷害及能量消耗。
7. ultimate()：處理 Q 大絕的蓄力、影格播放、命中傷害與收招。
8. loop()：每一個動畫影格更新移動、跳躍、敵人追擊、受傷、過關及 HUD。
9. 首頁與彈窗：處理開始畫面、設定、教學、排行榜和返回首頁。
10. 按鈕與鍵盤事件：把滑鼠／觸控和鍵盤輸入轉成遊戲動作。

常見名稱簡介
- hp / mp：玩家血量／能量。
- x：角色在遊戲世界中的水平位置。
- cameraX：鏡頭目前向右移動了多少。
- level / levelKills：目前關卡／本關擊敗數。
- enemyList：目前正在管理的敵人清單。
- keys：目前哪些方向鍵仍被按住。
- running / paused：遊戲是否正在運行／是否暫停。
- updateHud()：更新血量、能量和關卡文字。
- setup()：重設並開始一局遊戲。
- attack(kind)：處理一般攻擊；kind 代表攻擊種類。
- ultimate()：執行角色大絕。
- loop(t)：遊戲每幀都會執行的更新函式。

重要提醒
這次是排版與閱讀說明整理，不是功能重寫。請仍然測試開始遊戲、移動、跳躍、Z 槍刺、X 盾擊、Q 大絕、暫停、重新開始和四關流程。若有任何異常，先不要繼續拆檔，回到上一個成功版本比較。
