# 第三章測試關：水晶洞升降機

## 開啟方式

1. 解壓整個 `prince_game_chapter3_elevator_test.zip`。
2. 進入解壓後的 `prince_game_organized` 資料夾。
3. 用 Chrome 或 Edge 開啟 `chapter3_elevator_test.html`。
4. 這個入口會自動進入升降機測試關，不需要先經過遊戲首頁選關。不要把 HTML 單獨搬離專案資料夾，因為它會讀取同一資料夾中的 `images`、`styles`、`js` 和 `audio`。

## 玩法

- 使用整理版原有的角色、移動物理、跳躍、槍刺、盾擊、特殊技、敵人 AI、動作動畫、HUD、背景音樂與觸控按鈕。
- 測試怪物使用 `chapter1_enemy_1` 素材，對應程式中的敵人類型 `assassin`。
- 共 25 隻怪物，分 5 波，每波 5 隻；當前一波全部被擊敗後，約 1 秒後出現下一波。
- 戰鬥期間後景向畫面下方移動，表現升降機持續上升。
- 第 5 波全部清除後，升降機及後景停止；主角向右移動，經過出口畫面後切換至碼頭場景。

## 操作

- `←` / `→` 或 `A` / `D`：左右移動
- `↑`：跳躍
- `Z`：槍刺
- `X`：盾擊
- `C`：特殊技能
- 亦可使用畫面底部的觸控按鈕。

## 啟動問題修正（2026-10-25）
